Um welche Anwendung es geht

Der geld.pinguin Uploader erzeugt kurze Finanzbildungs-Videos und veröffentlicht sie auf den Social-Media-Kanälen des Betreibers. Die Anwendung wird ausschliesslich vom Betreiber selbst für dessen eigene Kanäle genutzt. Sie hat keine weiteren Nutzerinnen und Nutzer, keine Registrierung und keine öffentlich zugängliche Oberfläche.

Verarbeitete Daten

Zugangsdaten des Betreibers

Damit die Anwendung Videos in den eigenen YouTube-Kanal hochladen kann, erteilt der Betreiber ihr einmalig über Google OAuth eine Berechtigung. Dabei entstehen und werden gespeichert:

DatumZweckSpeicherort
OAuth-Refresh-TokenErneuerung des kurzlebigen Zugriffstokens vor jedem UploadVerschlüsseltes GitHub-Actions-Secret
OAuth-Client-ID und -SchlüsselIdentifikation der Anwendung gegenüber GoogleVerschlüsseltes GitHub-Actions-Secret

Diese Daten betreffen ausschliesslich das Konto des Betreibers.

Daten Dritter

Die Anwendung erhebt, speichert und verarbeitet keine Daten anderer Personen. Sie ruft keine Zuschauerdaten ab, liest keine Kommentare, greift auf keine Kontaktlisten zu und verfügt über keine Anmeldung für Dritte.

Reichweitenzahlen

Zur Auswertung der eigenen Beiträge ruft die Anwendung aggregierte Kennzahlen der eigenen Veröffentlichungen ab, etwa Aufrufe und erreichte Konten je Beitrag. Diese Zahlen sind zusammengefasst und lassen keine Rückschlüsse auf einzelne Personen zu.

Diese Website

Diese Seiten werden über GitHub Pages bereitgestellt und enthalten keine Cookies, keine Analysewerkzeuge und keine eingebetteten Inhalte Dritter. GitHub verarbeitet beim Abruf technisch notwendige Verbindungsdaten wie die IP-Adresse. Näheres dazu in der Datenschutzerklärung von GitHub.

Zugriff auf Google-Nutzerdaten

Die Anwendung verwendet ausschliesslich den Berechtigungsbereich https://www.googleapis.com/auth/youtube.upload. Dieser erlaubt allein das Hochladen von Videos in den Kanal des angemeldeten Kontos.

Die Verwendung von Informationen, die über Google-APIs bezogen werden, entspricht den Google API Services User Data Policy einschliesslich der Anforderungen zur eingeschränkten Verwendung (Limited Use).

Konkret bedeutet das:

  • Die Daten werden ausschliesslich dafür verwendet, die vom Betreiber selbst erstellten Videos in dessen eigenen Kanal hochzuladen.
  • Es findet keine Weitergabe an Dritte statt.
  • Es findet keine Nutzung für Werbung statt.
  • Es werden keine Daten für Modelltraining oder ähnliche Zwecke verwendet.
  • Kein Mensch liest diese Daten, ausser wenn der Betreiber dies zur Fehlersuche an seinen eigenen Daten tut oder es gesetzlich vorgeschrieben ist.

Speicherdauer und Löschung

Das Refresh-Token bleibt gespeichert, solange die Anwendung genutzt wird. Es wird gelöscht, sobald das entsprechende Secret im Repository entfernt oder der Zugriff bei Google widerrufen wird.

Der Betreiber kann den Zugriff jederzeit selbst entziehen unter myaccount.google.com/permissions. Danach ist kein Upload mehr möglich; das gespeicherte Token verliert seine Gültigkeit.

Weitergabe

Es findet keine Weitergabe von Daten an Dritte statt. Technisch beteiligt sind ausschliesslich die Dienste, über die die Anwendung läuft: GitHub für die Ausführung und Speicherung der Secrets sowie Google und Meta als Zielplattformen der Veröffentlichung.

Rechte

Da ausser den Zugangsdaten des Betreibers keine personenbezogenen Daten verarbeitet werden, entstehen für Dritte keine betroffenen Rechte im Sinne der DSGVO. Fragen zur Anwendung beantwortet der Betreiber unter der oben genannten Adresse.

Ändert sich die Funktionsweise der Anwendung, wird diese Erklärung angepasst. Der oben genannte Stand gibt die jeweils gültige Fassung an.
